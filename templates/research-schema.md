# Research Schema Add-on

Use this add-on when the wiki tracks papers, books, scientific literature,
evidence maps, or research workflows.

## Required Source Metadata

For scientific literature, add these fields when available:

- `source_kind`
- `authors`
- `title`
- `year`
- `venue`
- `publisher`
- `doi`
- `isbn`
- `url`
- `raw_source`

## Source Kinds

- `paper`
- `preprint`
- `book`
- `chapter`
- `report`
- `thesis`
- `dataset`
- `article`
- `transcript`

## Evidence Tags

Add relevant tags before use:

- literature
- paper
- book
- preprint
- dataset
- method
- evidence-map
- limitation
- contested

## Research Workflow Rule

The wiki can provide context and source packets to research workflows, but it
does not replace independent evaluation, peer review, or methodology review.
