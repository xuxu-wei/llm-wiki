# {{domain}} LLM Wiki

This plain-Markdown wiki preserves source material separately from compiled,
cross-linked knowledge. `AGENTS.md` contains the operating contract for agents;
this README is a human-facing map.

## Contents

```text
raw/inbox/        Material awaiting classification
raw/articles/     Web and documentation originals
raw/papers/       Literature and document originals
raw/transcripts/  Spoken or conversational originals
raw/data/         Tables and datasets
raw/media/        Images, audio, video, and attachments
raw/derived/      Text derived from preserved originals
sources/          Source summaries and provenance
entities/         Durable named things
concepts/         Durable ideas and methods
syntheses/        Cross-source conclusions
comparisons/      Side-by-side analyses
queries/          Reusable filed answers
_meta/            Taxonomy and administrative material
_archive/         Preserved superseded pages
```

`index.md` is the generated content catalog. `log.md` is the append-only record
of successful changes and requested audits.
